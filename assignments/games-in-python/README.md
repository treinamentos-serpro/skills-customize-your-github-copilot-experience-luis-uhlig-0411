
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, laços de repetição e entrada de dados do usuário em Python.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador adivinhe letras para revelar uma palavra oculta antes que as tentativas acabem. Use manipulação de strings, laços de repetição, condicionais e seleção aleatória.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Aceitar palpites de letras e mostrar o progresso atual (formato `_ _ _`)
- Rastrear o número de tentativas incorretas restantes
- Encerrar quando a palavra for adivinhada ou as tentativas acabarem
- Exibir uma mensagem de vitória ou derrota
